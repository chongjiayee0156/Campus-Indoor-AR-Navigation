<h1 align="center">Campus Indoor AR Navigation App</h1>

> An Android-based Augmented Reality navigation app that provides indoor directions with voice and AR guidance, powered by BLE beacons and Mapbox.

---

## 🚀 Features

- 🎙️ **Voice Navigation** – Step-by-step voice guidance through indoor paths  
- 🧭 **Augmented Reality** – AR-powered route visualization for immersive indoor navigation  
- 🗺️ **Map View** – Interactive 2D map powered by **Mapbox API**  
- 📡 **Localization** – Accurate indoor positioning using **Bluetooth Low Energy (BLE)** beacons

---

## 📋 Requirements

- Android Studio
- Android device with BLE support
- BLE beacons deployed across campus

## 📌 Notes

- Floor plans are integrated using data scraped from the **MazeMap API**
